# 프로젝트 개요
Spring 6기 플러스 주차 과제 (걷기반)

기능

1 User : 회원가입, 로그인 기능

2 Schedule : 일정 CRUD

  - 전체 조회 : 페이징처리, 코멘트 개수 처리
  - 단건 조회

3 Comment : 댓글, 대댓글 CRUD
  - 부모 댓글, 자식 댓글 : Depth 1
  - 댓글 페이징, 자식 댓글 카운팅 기능
